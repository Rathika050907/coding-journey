# Coding Journey & Personal Tracker

Welcome to my comprehensive personal tracking system that combines coding progress, health monitoring, and work productivity tracking. This repository serves as both a learning journal and a holistic life tracker.

## 📚 Repository Overview

This repository contains:
- **Daily coding practice logs** - Documenting my journey through competitive programming
- **Personal tracking templates** - Comprehensive health and work monitoring tools
- **Progress documentation** - Tracking growth across multiple life dimensions

## 🗂️ Repository Structure

### 📊 Tracking Templates
- **`health-tracker-template.md`** - Comprehensive health and wellness tracking
- **`work-tracker-template.md`** - Detailed work productivity and project management
- **`daily-tracker-template.md`** - Integrated daily tracker combining health, work, and coding
- **`sample-daily-tracker.md`** - Example of how to use the daily tracker

### 💻 Coding Journey Files
- **`day1.md` to `day12.md`** - Daily coding practice logs with problem solutions
- Each day file contains:
  - Problem statements and links
  - Solution approaches and algorithms
  - Key learnings and insights
  - Time complexity analysis

## 🎯 How to Use This System

### For Personal Tracking

1. **Choose Your Tracking Style:**
   - **Focused Tracking:** Use individual templates (`health-tracker-template.md` or `work-tracker-template.md`)
   - **Holistic Tracking:** Use the integrated `daily-tracker-template.md`

2. **Create Daily Entries:**
   ```bash
   # Copy the template you want to use
   cp daily-tracker-template.md tracker-23-09-2024.md
   
   # Fill in your daily information
   # Save with consistent naming: tracker-DD-MM-YYYY.md
   ```

3. **Customize Templates:**
   - Modify sections based on your specific needs
   - Add or remove tracking categories
   - Adjust metrics and goals to match your lifestyle

### For Coding Practice

1. **Follow the Day Structure:**
   - Copy the format from existing day files (`day1.md`, `day2.md`, etc.)
   - Include problem links, approaches, and learnings
   - Document time complexity and space complexity

2. **Track Your Progress:**
   - Note difficulty levels and time spent
   - Record key insights and patterns learned
   - Plan tomorrow's focus areas
